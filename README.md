### 🎯 Sobre esta Aplicação

Este repositório hospeda a interface web interativa do projeto **VigIA Comunitária & Alerta Encosta**, desenvolvido para a **FIAP Global Solution 2026.2**.

A aplicação permite a visualização em tempo real de:
1. **Índice Hiperlocal de Risco (HRI):** Fusão sensorial de lâmina d'água (HC-SR04), saturação do solo, índice pluviométrico, visão computacional e relatos de moradores.
2. **Simulador Interativo de Cenários:** Botões dedicados no topo para alternar entre *Tempo Estável*, *Alerta de Encosta* e *Tempestade Severa com Evacuação*.
3. **Canal do Cidadão com NLP e LGPD:** Formulário para envio de relatos populares com triagem automática de urgência e anonimização de dados sensíveis (Art. 13 da LGPD).
4. **Rotas Táticas de Evacuação:** Visualização cartográfica com identificação de abrigos recomendados e acessos interrompidos.
5. **Acessibilidade Radical (WCAG):** Modo de Alto Contraste nativo para visualização sob sol forte, chuva ou baixa luminosidade.
